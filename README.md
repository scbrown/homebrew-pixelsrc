# homebrew-pixelsrc

Homebrew tap for [pixelsrc](https://github.com/scbrown/pixelsrc), whose CLI is `pxl`.

```bash
brew install scbrown/pixelsrc/pxl
```

That is shorthand for `brew tap scbrown/pixelsrc && brew install pxl`. Prebuilt binaries
for macOS (Apple Silicon and Intel) and Linux (x86_64 and ARM64).

`Formula/pxl.rb` is regenerated by the pixelsrc release workflow on every release; edit
`.github/workflows/homebrew.yml` in the pixelsrc repo, not this file.
